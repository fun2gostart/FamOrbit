# Project Rules & Device Guidelines

## Device Interaction Protocol
- **Autonomous Emulator Inspection**: Run safe emulator inspection actions autonomously for emulators, including swipes, screenshots, and UI inspection.
- **Confirmation Required**: Ask for explicit confirmation before:
  - Any installation
  - Any deletion
  - Any file modification
  - Any device-setting change
  - Any network action
  - Any command targeting a device other than emulators (e.g. physical devices connected via USB or wireless ADB).
